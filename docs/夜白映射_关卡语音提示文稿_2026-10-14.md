# 夜白映射｜关卡语音提示文稿

日期：2026-10-14 · 配音稿 v1.1 · 已按团队指定的 PRD 修订

## 1. 使用依据与录制说明

**规则基准：**《夜白映射游戏产品需求文档》v1.0。采用固定配对、共同推动与独立阻挡、实体虚影、唯一映射名额、真实状态保留、传送门穿行，以及主动请求的三层提示。团队此前确定的单世界观察方式继续适用，台词只说动作，不固定按键。

**扩展依据：**《夜白映射：机制研究与关卡设计分析》。其中 E01—E08 是尚未定图的实验候选；新增物件只有在对应规则明确、功能完成后才能使用相关台词。

本稿中的 L01—L08 保留 PRD 的原文编号，E01—E08 保留研究稿编号，便于团队按最终选定的关卡取用。它们不规定本次必须制作的关数，也不将旧五关映射对照版、当前逻辑门课程与 PRD 八关混用。若最终合并为五关，按实际教学内容选取台词、调整编号和可见标记。

**讲述者建议：午夜学院的引导员。** 平静、亲切，像陪玩家做实验。入场让人知道目标，提示让人知道接下来观察什么；发现反馈在玩家看到现象后，帮助他说清原因。

- 只录表格中的“配音正文”。编号、条件、知识说明都不读。每个编号单独录一条，便于接入和替换。
- 普通语速，逗号处稍停，疑问句轻收尾。多数短句预计约 5—12 秒，较长提示约 12—20 秒；按实际试读调整。
- “映射”读 yìng shè，“虚影”读 xū yǐng。统一称呼“夜世界、白世界、真实物体、虚影”；不把虚影说成不可碰的幻觉。
- 不报坐标或公式。第一、第二座桥和一号、二号门座应与画面标记一致。
- IN：入场目标。H1：观察对象。H2：相关规则。H3：具体下一步或示范路线。DISC：关键现象发生后的短反馈。CLEAR：整关成功后的学派札记，最多两句。
- H1—H3 由玩家主动请求，逐级提供；不因短暂停顿自动播答案，也不惩罚使用提示。已完成对应步骤时跳过旧提示。
- DISC 不提前剧透，一次实验发现只播一次。CLEAR 接受合法替代解，不要求复现标准路线；是否通关由实际目标决定。
- 一次只播一条，切关取消旧队列。失败提醒可以打断普通提示；字幕与正文一致，支持重听和关闭语音。

**黑客松最小录音包：** 若采用 PRD 的六个基础模块，先录 `SYS_WELCOME`、`SYS_OBSERVE`、`SYS_RETURN`、`SYS_FAIL`，再录 L01、L02、L04、L05、L06、L08 的 IN 与 CLEAR，共 16 条。随后补分层提示。新机制优先补 E01—E04；这只是录音工作量建议，最终关数以团队选择为准。

## 2. 通用引导与状态提醒

| 编号 | 播放时机 | 配音正文 |
| --- | --- | --- |
| SYS_WELCOME | 首次进入，一次 | 欢迎来到午夜学院。夜与白两个世界，藏着不同的道路。先观察，再试一试，我们从一个小实验开始。 |
| SYS_OBSERVE | 首次主动切换观察，完成切换后 | 你现在看到的是另一个世界。身体还在原处，留意画面上的身体标记。 |
| SYS_RETURN | 观察另一世界时尝试走路；本次状态只播一次 | 你正在观察另一边。切回身体所在的世界，才能继续走路。 |
| SYS_PREVIEW | 首次预览另一组，原组仍有效 | 现在只是预览。确认之前，原来的映射仍然有效。 |
| SYS_GENERATE_BLOCKED | 新虚影生成与实体冲突；画面同时标出冲突物 | 这里没有足够的生成空间。看看预览中挡住它的物体；原来的映射还在。 |
| SYS_FAIL | 失去支撑，进入失败或恢复流程 | 脚下的支撑消失了。你可以撤销这一步，或者从安全点再试一次。 |
| SYS_UNDO | 首次成功撤销，可选 | 撤销会恢复上一步的完整状态。反向推动，则是按现在的环境再做一次动作。 |
| SYS_SAFE_SWITCH | 预览会移除身体脚下的虚影桥；确认前提示一次 | 这次切换会撤掉你脚下的桥。先走到永久地面，再确认。 |

`SYS_SAFE_SWITCH` 作为非阻断提醒，不弹确认框、不禁止解除。预览本身仍不撤桥；真正解除或合法替换后才重新结算支撑，符合 PRD F05—F10。

## 3. PRD 基础关卡提示库

本节对应 PRD 第 09 节的布局与示范解，是该布局下的配音方案，不声称当前游戏已经实现这八关。

### L01｜同一指令

核心发现：按身份绑定真实物体，推动会同时传向关联两端；观察不移动身体。

| 编号 | 播放时机 | 配音正文 |
| --- | --- | --- |
| L01_IN | 入场 | 让两个世界的箱子都进入目标槽，再走到夜世界的终点。先看看，两边哪些物件带着相同符号。 |
| L01_H1 | 第一次请求提示；尚未建立映射 | 比较箱子上的身份符号。另一边，哪件物体与它对应？ |
| L01_H2 | 第二次请求提示；尚未建立映射 | 选中带标记的真实箱子，确认映射。这一对箱子，就会收到同一个推动方向。 |
| L01_H3 | 请求具体操作；两箱仍在 PRD 初始位置 | 激活箱子映射，向右推动两次。两侧目标亮起后，切回夜世界的身体视角，走到终点。 |
| L01_DISC | 首次共同推动成功，两端确实移动 | 这一次推动，两边都收到了。它们的对应身份，会一直保持。 |
| L01_CLEAR | 双槽满足，身体抵达终点 | 你建立了两件真实物体的联系。观察、映射和走路，各自改变不同的状态。 |

H3 的“两次”只用于原文初始状态；已经推过或改图后，应按当前目标给下一步，不能照播。双槽已满足时使用 `L_TARGETS_READY`。

### L02｜墙边的把手

核心发现：一端受阻不取消另一端的推动；受阻端仍能作为输入入口。

| 编号 | 播放时机 | 配音正文 |
| --- | --- | --- |
| L02_IN | 入场 | 两侧的目标，离起点并不一样远。看看夜侧的止挡，它会怎样改变同一次推动？ |
| L02_H1 | 第一次请求提示 | 比较两个箱子右边的空间。夜箱停住以后，白箱还有没有路可走？ |
| L02_H2 | 第二次请求提示 | 两端收到同一个方向，各自判断能不能动。夜侧被挡住，不会取消白侧的推动。 |
| L02_H3 | 请求操作；双目标尚未完成 | 激活箱子映射。先向左推到两端都停住，再向右推动三次；夜侧停住时，继续观察白侧。 |
| L02_DISC | 首次夜端受阻、白端继续移动 | 看，夜侧停住了，白侧还在前进。停住的箱子，也可以是操作另一端的把手。 |
| L02_CLEAR | 双槽满足，身体抵达终点 | 你借用了墙边的止挡。相同的推动，在不同约束下留下了不同的结果。 |

H3 的校准适用于 PRD 夜轨 2—3、白轨 2—6、目标 3/5。它是面向已推乱状态的稳妥示范；初始状态直接向右三次也成立。

### L03｜错位校准

核心发现：先借左止挡制造位差，再让两个箱子同时到不同目标。

| 编号 | 播放时机 | 配音正文 |
| --- | --- | --- |
| L03_IN | 入场 | 两个箱子从同一位置出发，目标却不对齐。试着安排它们之间的差别，再一起走向目标。 |
| L03_H1 | 第一次请求提示 | 只向右推时，两个箱子会同时到槽里吗？再比较两侧的左端尽头。 |
| L03_H2 | 第二次请求提示 | 让夜箱被左侧止挡留住，白箱继续向左。两边重新向右走时，已经形成的差别就会留下。 |
| L03_H3 | 请求操作；目标未同时满足 | 激活箱子映射，向左推到两端都停住，再向右推两次。确认两个目标同时亮起。 |
| L03_DISC | 首次形成有效的夜右白左位差 | 你先改变了两个箱子的相对位置。接下来，共同移动就能保留这段差别。 |
| L03_CLEAR | 两目标同时满足并完成出口条件 | 先远离目标，反而帮助你完成了校准。止挡让你有办法主动安排位置差。 |

PRD 的目标是夜 5、白 3；从初始状态左两次、右两次。不要混用旧五关终局的“右三次”和目标 6/4。

### L04｜门后的路

核心发现：远程安排白侧真箱；身体经传送门借白走廊绕过夜墙。

| 编号 | 播放时机 | 配音正文 |
| --- | --- | --- |
| L04_IN | 入场 | 夜世界的出口在墙后。先看看白世界的走廊，再找找能让身体过去的门座。 |
| L04_H1 | 第一次请求提示 | 留意身体标记。墙两侧的一号、二号门座，分别连着哪里？ |
| L04_H2 | 第二次请求提示 | 观察不会带走身体。先让白箱压住白踏板，再从一号门座进入白世界的走廊。 |
| L04_H3 | 请求路线；身体尚在起始区域 | 先用箱子映射打开白走廊门。从一号门座到白世界，穿过走廊，再从二号门座回夜侧，走向出口。 |
| L04_DISC | 身体首次经传送门到白世界 | 这次身体也过来了。你可以借这条走廊，走到夜墙的另一侧。 |
| L04_CLEAR | 身体抵达夜侧出口 | 你先安排了另一边的状态，再亲自借用了它的道路。两个世界共同组成了一条路线。 |

白门已经开启时不重复摆箱；身体已经过门时改播 `L04_AFTER_DOOR`，不要求回到起点。

### L05｜借来的桥

核心发现：无真实对应物的固定桥，在另一世界生成可站立的实体虚影。

| 编号 | 播放时机 | 配音正文 |
| --- | --- | --- |
| L05_IN | 入场 | 两边都有沟壑，白侧却多了一座桥。看看它的映射标记，能不能把这段结构借到夜侧。 |
| L05_H1 | 第一次请求提示；尚未借桥 | 去白世界观察。哪件结构，正好跨过夜侧缺少道路的位置？ |
| L05_H2 | 第二次请求提示 | 这座桥没有真实对应物。映射后，夜侧会出现同坐标的实体虚影桥，能够支撑身体。 |
| L05_H3 | 请求操作；桥未激活 | 选中白侧真实桥，确认夜侧的生成预览。激活后切回夜侧，保持映射，走过桥面。 |
| L05_DISC | 首次合法激活桥映射 | 夜侧的桥出现了。它有可站立的表面；只要这组映射还在，支撑就还在。 |
| L05_CLEAR | 身体过桥并完成终点条件 | 你把另一侧的结构借成了脚下的道路。虚影的存在，能够产生实体的作用。 |

白侧是桥的真实源，夜侧是虚影。固定桥不能推移；不把真实桥与虚影颠倒，也不提示从虚影再生成新桥。

### L06｜唯一的名额

核心发现：先借桥到安全岛，再换另一座桥；无需两座虚影同时存在。

| 编号 | 播放时机 | 配音正文 |
| --- | --- | --- |
| L06_IN | 入场 | 两条沟壑，一组映射。先看看中间的小岛，哪块地面可以让你安心换下一座桥？ |
| L06_H1 | 第一次请求提示 | 两条沟壑之间，哪里即使没有映射，也仍然能站稳？ |
| L06_H2 | 第二次请求提示 | 新组生效时，旧虚影会消失。先到永久地面，再换桥；你已经到达的位置会留下。 |
| L06_H3 | 请求路线；身体尚未过第一沟 | 借第一座桥，走到安全岛。站稳后预览并确认第二座桥，再过第二条沟壑，走向终点。 |
| L06_DISC | 身体首次在安全岛的永久地面站稳 | 这里不依赖虚影。第一段路已经走完，你可以安排接下来的桥了。 |
| L06_CLEAR | 身体抵达终点 | 一个名额，先后提供了两段路。安全落脚点让你有机会改变临时结构。 |

原文白桥 A/B 分别为第一、第二座桥，不与其他关卡的箱 A 混称。桥上预览不撤桥；只有合法确认后才替换。

### L07｜留下的结果

核心发现：真实箱持续压板开本地门，解除联系不归位；名额可以交给桥。

| 编号 | 播放时机 | 配音正文 |
| --- | --- | --- |
| L07_IN | 入场 | 夜侧真箱能压住踏板，过沟壑却还需要桥。想想，哪一项工作做完以后，可以留在原处？ |
| L07_H1 | 第一次请求提示 | 门是因为箱子还在踏板上开启，还是必须靠映射一直维持？ |
| L07_H2 | 第二次请求提示 | 解除真实箱的联系，它们不会归位。真箱仍压着本地踏板，接触作用就仍然有效。 |
| L07_H3 | 请求操作；身体处于安全地面 | 先把夜侧真箱推到夜踏板上，再把映射交给白侧的桥。真箱留住门，你借夜侧虚影桥走过去。 |
| L07_DISC | 切换到桥后，夜箱仍在板上、夜门仍开启 | 箱子还在，门也还开着。保留下来的真实摆放，让名额可以交给桥。 |
| L07_CLEAR | 身体过桥并抵达出口 | 真实位置留下了，临时结构接上了。你安排了两种状态不同的存在方式。 |

这里是夜箱、夜踏板、夜出口门的本地连接，不能用白踏板直接开夜门。门的维持原因是当前接触，不是曾经触发过。

### L08｜学派交汇

核心发现：白箱状态保留、两次借桥、身体传送路线共同组成完整解法。

| 编号 | 播放时机 | 配音正文 |
| --- | --- | --- |
| L08_IN | 入场 | 两座桥、一道白门，还有中央岛上的夜墙。把路线分成几段，先想哪件事能提前做好。 |
| L08_H1 | 第一次请求提示 | 哪个真实物体能留住门？两段沟壑之间，又哪里可以安全换组？ |
| L08_H2 | 第二次请求提示 | 真箱可以留住白门，名额先后借给两座桥。中央的夜墙，则需要身体借白走廊绕过。 |
| L08_H3 | 请求完整路线；身体尚在起始区域 | 先让白箱压住踏板，再借第一座桥到中央岛。经一号门座穿过白走廊，从二号门座回夜侧，最后站稳换第二座桥。 |
| L08_DISC | 箱位工作完成、合法换成第一桥后；门确实保持开启 | 真箱仍在维持白门。你可以让名额去搭桥，已经做好的真实工作不会随换组消失。 |
| L08_CLEAR | 实际整关目标满足 | 你让真箱留住条件，让虚影提供支撑，再让身体穿过两个世界。几个简单规律，组成了完整的路线。 |

PRD L08 没有指定旧五关终局的 6/4 双箱校准或桥末端验收条件，不在此加入这些目标。H3 只在对应初始区域播；已完成阶段使用下面的短句。

## 4. 新机制实验：选定并实现后使用

按研究稿原编号 E01—E08 保留模块身份，方便团队取用；编号不规定最终关卡顺序。建议先教共同输入和独立阻挡，再使用 E01、E02。E03 需要先让玩家辨认真实源与虚影；E04 应在此之后。

| 模块 | 使用前提 |
| --- | --- |
| E01 | 具有不同止挡的真实配对箱；需要往返位差的目标 |
| E02 | 可调整的真实止挡；换组后保持其位置；碰撞已明确 |
| E03 | 可移动无对应物箱、独立虚影位置、删除与合法重生成 |
| E04 | E03 的真实源/虚影模型；虚影确实堵住必要通路 |
| E05 | 未映射真实箱可以近身推动；已提前教过近推操作 |
| E06 | 新型宽踏板明确接受身体、真箱和虚影；有不重叠的接力空间 |
| E07 | 遮光片与虚影确实改变本世界光路；反馈与碰撞一致 |
| E08 | 凹形框架按真实形状碰撞；两端可接触踏板，孔洞可通行 |

## 5. 录制与接入核对

1. 音频按编号命名，例如 `L02_H1.wav`、`E03_H2.wav`。纯配音版采用相同编号，只保留正文与录音分组。
2. 给每条音频配一致字幕；允许主动重听，提示使用不扣进度。通关札记不妨碍继续游戏。
3. 播放前判断身体所在区域、目标完成状态、当前映射和虚影存在性。事件条件已不成立的台词取消播放；先处理失败，再处理普通提示。
4. L01 的“两次”、L02 的“三次”、L03 的“两次”都对应 PRD 指定布局。换图或修改步长后重新核对。不要把研究稿 E01 的实验操作当成任何布局都成立的最终解。
5. 新机制正式定图后，走完真实路线，再复核 H3、DISC 和触发条件。实验草图没有完整坐标、身体路径和所有机关状态，本稿不补造格数或唯一解。
6. 学派札记解释刚刚观察到的规则，不讲量子纠缠、不宣称同样推力必然产生同样位移，也不把虚影重生成说成现实物体穿墙。
7. 身体压宽踏板、实体遮光、凹形框架都需要物件明确教学。玩家挤门、移动桥承载、影子再生影子和跨世界机关通电不纳入本稿提示。
8. 配音完成后做一次不看文稿的试玩：入场能否听懂目标，H1 能否带来有效观察，H2 能否帮助预测，H3 是否与当前状态匹配。录音条数不是教学效果的证据。
