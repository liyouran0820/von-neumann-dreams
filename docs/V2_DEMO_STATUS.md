## 运行与版本

```bash
npm ci
DEMO_PORT=5174 npm run dev
```

打开[本机十三关](http://127.0.0.1:5174/?version=v2)。同一选馆菜单有“入学试炼（原版）”与“2.0关卡”，共18个主入口；无参数默认旧五关。`?version=original`与`?version=optics`继续保留三套旧五关的数据和玩法。以上localhost链接仅在运行服务的电脑上有效。

服务器单文件交付使用`npm run build -- --default-version=v2`，`dist/index.html`默认进入十三关，无需追加查询参数。导出属性只改变该文件的默认目录；开发入口默认旧五关保持。显式`?version=academy`可打开旧关，菜单切换后的刷新保持所选版本。

2.0 ID为`V2-01`至`V2-13`；进度和札记分别使用`night-white-v2-progress`、`night-white-v2-notes`，以版本格式和稳定ID保存。欢迎状态独立。旧存档不迁移、不覆盖；清除2.0经过确认且不改变三套旧进度。禁用或损坏存储仍可玩。第五关可继续到第六关，第十三关为末关。

WASD走路与近推，方向键推动当前组，Space只切观察，E确认映射，Q解除，Z撤销，F在门座穿行。Tab选源；可转镜面用1/2选择、R转动，也可点击同名按钮。固定镜面没有转动入口。普通配重K不接受远程推动或映射；对应真箱A解绑留位，G解绑删除虚影，Q后E从源当前位置重生成。

## 用户试玩反馈

- 02/04此前反馈：用户明确“箱子”指夜白对应A，双靶同时到位才判胜。此前可先到出口后补靶的旧02测试保留在历史摘要；按下面最新双AND要求，当前02缺任一靶时门不会打开，04仍允许出口旁校准。
- 01最新修订：删除夜K及b板，白靶B成为真实AND输入，Y=A AND B。四种实际箱位均符合真值，只有两靶同亮才开门。
- 02最新修订：保留K与夜b板，夜靶a和白靶w先进入AND得到C，再由C与b进入第二个AND得到Y。八种实际输入通过；双靶到位而b空时C=1/Y=0，推K上板后Y=1，撤销可恢复。01/02/05采用指定端点和输出对象白名单，其余关卡继续禁止跨世界物理接线。
- 08/09：原设计直接用轨靶开门，缺少逻辑门。按反馈增加K=N(2,1)、b板=N(2,0)，08使用Y1=p AND b，09使用Y1=p AND b、Y2=q AND b；两输入都可独立改变。场景、电路、目标、三层提示和参考路线同步更新。
- 10白侧空场景：补齐10对应的平地与必要分隔；排查到12同类空白后一并补齐。两关白侧供观察，电路仍在夜侧，未增设映射源或身体传送。
- G删除后重生成直接出现在源的新坐标；修复旧模型从3滑到5、视觉穿墙的问题，实时帧证明可见位置均为5。
- 新受力动作沿用360ms压缩/回弹；只有已贴住且继续同向受阻才播放，到达止挡不播放。修复RAF帧时间戳早于输入时误清掉刚开始的动作；保留既有减少动态偏好和900ms掉落动作。
