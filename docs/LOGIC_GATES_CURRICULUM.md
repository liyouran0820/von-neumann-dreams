## 五关

| 关卡 | 学习内容 | 输入与实际用途 |
| --- | --- | --- |
| G1 入口庭院 | 与门AND | A=夜箱在3，B=白箱在5；输出为两项同时成立的公开验收逻辑，不接成跨世界机关电路 |
| G2 回廊 | 或门OR | 白侧A=箱踏板，B=实验开关；任意一路亮都能打开白门，也接受双亮和只用开关的路线 |
| G3 断桥馆 | 非门NOT | 白侧受光A初始为1，非门关闭；转镜让A灭，输出变1，光门打开；仍需借桥和穿行 |
| G4 双院 | 异或门XOR | 两个开关共同控制前后两门；输入相同则前门开，输入不同则后门开，仍需复用两座桥 |
| G5 天文台 | 与非门NAND及组合 | 白侧A=踏板，B=受光。第一门C=非(A与B)，第二门两端同接C，得到Y=非C，合成为与门；门需要踏板和光输入都亮 |

## 第二关穿模修复

此前开关只有3D模型，未进入规则碰撞。现在`instrumentAt`统一提供开关、镜面、光源和感应器的占格；`support`、键盘移动、寻路及传送落点共用判断。人物不能进入器材格，点击寻路会绕开。器材模型本身也支持拾取交互，点击器材不会把人物送入底座。

关闭逻辑门时，当前门内角色允许离开，其他角色位置不能作为新进入许可。开关、镜面方向进入完整撤销；札记独立保留已经看过的输入输出。
