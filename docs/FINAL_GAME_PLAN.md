## 1. 形式与核心

The Midnight Academy 主题下的单人空间解谜小游戏。学院具有夜与白两个世界；共享坐标、边界与天然沟壑，墙、门、桥和物件可以不同。

**一次推动作用于一对真实箱子，两端根据各自障碍独立决定能否前进。** 同一输入可以产生不同位移，箱子的身份对应不会因为位置偏差而改变。

身体与观察分开：观察另一世界可以安排物件，但不会把身体送过去；身体必须通过传送门穿行。后续映射固定桥，在另一世界生成可站立的实体虚影；唯一名额要求玩家在安全地面分时使用不同桥。

## 2. 统一规则

| 项目 | 当前规则 |
| --- | --- |
| 对应身份 | 关卡指定，真实箱 A 固定配对，无自由选目标或临时重配 |
| 推动 | 同一方向输入分别在两端推进一个逻辑步；一端受阻不取消另一端 |
| 绑定与解除 | 不对齐、不归位；解除真实箱配对保留两端当前位置 |
| 映射名额 | 同时至多一组：一对真实物件，或一个真实桥与另一世界的虚影 |
| 无对应物 | 在另一世界同坐标生成完整实体桥，固定桥不可推动 |
| 虚影身份 | 依赖当前映射存在，不能作为源再生新的虚影 |
| 预览 | 不提供支撑，也不移除旧映射；清楚提示替换后将消失的桥 |
| 激活与替换 | 合法后原子提交；生成不合法时保留旧映射和所有真实状态 |
| 观察与身体 | 切换观察不改变身体；看另一世界时禁止身体移动，远程映射和推动可用 |
| 穿门 | 只移动身体到另一世界同编号安全落点，保留映射与物件状态 |
| 机关 | 只由本世界踏板持续接触控制，离开目标立即灭灯，无隐藏跨世界电路；网页格子版身体占住门洞时暂不关门，身体离开后立即关闭，不锁存开门状态 |
| 失败 | 桥消失后立即更新支撑；脚下无支撑进入可撤销失败，不等待动画才判定 |
| 恢复 | 完整撤销和进入安全区域时的完整检查点快照，不替玩家补桥或校准箱位 |

远程操作不设置距离、视线、能量或冷却限制。玻璃只拦身体，不能拦映射。初版不增加跳跃、冲刺、旋转、堆叠、自由配对、第二名额或限时门。

跨世界映射与虚影是虚构能力；知识内容是对应、局部约束、实时状态和有限资源的顺序安排。逻辑步模型不宣称同样推力在现实中必然产生同样位移。

## 3. 五关递进

| 关卡 | 核心发现 | 必要身体路线 |
| --- | --- | --- |
| G1 入口庭院 · 墙也是工具 | 夜箱停在止挡，白箱继续，形成位差 | 双槽实时满足后抵达夜出口 |
| G2 回廊 · 看见不等于到达 | 先安排白门，再亲自穿行；解除后真箱状态留下 | 夜 P1 → 白门 → 白 P2 → 夜出口 |
| G3 断桥馆 · 把桥借给另一边 | 没有对应物时生成实体虚影 | 借夜桥到白侧，夜 P1 → 白虚影桥 → 白 P2 → 夜出口 |
| G4 双院 · 一席之地 | 在永久安全岛换用唯一名额 | 夜借 B 到岛，穿 P1/P2 绕夜墙，再借 C 到夜出口 |
| G5 天文台 · 逆向的答案 | 借左止挡制造位差，再组合真箱留存、临时桥与门 | 校准 A、借 B、穿白门、借 C；在夜 C 桥末端验收 |

完整坐标、初始地图、分层提示和合法换序以来源为准。G4 与 G5 允许多处安全地面换组，不能限定示范位置或顺序。

G5 标准校准为左、左、右、右、右：从夜 3 / 白 3 到夜 6 / 白 4。箱子目标实时检查，曾经经过不算完成。三个条件同时成立：夜 A 在 6、白 A 在 4，身体脚底中心位于夜 `(15,2)` 或 `(15,3)`，且实际由当前 C 虚影支撑。

验收图标没有独立地板。白真实 C、夜岸边、观察切换或撤桥后的坠落延迟均不能代替验收。允许先过桥后校准，或先到岸整理再返回验收环，不匹配参考步骤。

## 4. 简版操作与反馈

入口先明确目标和最少操作。选带标记的真实物件，看到固定配对或桥预览，再激活；左右按钮每次推动一步。身体移动与远程推动分开，传送门另有“穿门”操作。

常驻展示身体世界、观察世界、映射 0/1 或 1/1、公开目标。场景每次显示一个世界，Space点按往返切换；推动时操作反馈同时说明两端受阻或移动，当前场景显示对应位移。夜白保留世界标题与身份标记。

虚影以完整表面表示，预览为断续线；准备替换的旧桥有将消失提示。失败立即提供撤回、检查点恢复和重置。提示主动逐层打开，不预填答案、不扣奖励。

先用二维离散白盒检查五关逻辑；完整美术、连续移动手感、音效与盲测按实际证据继续迭代。所有主要操作提供可点击控件。

## 5. 验证与参赛表达

演示用 G1 的“一边停、另一边继续”建立局部约束概念；G2 区分看见与到达；G3 让玩家亲自走上生成桥；G4 展示安全岛上的名额复用；G5 展示先反向调整位差、保留真实状态、把名额交给桥后的综合完成。

来源自述已有离散搜索和机制删除检查。本仓库须单独验证正常五关、反事实规则、合法换序、完整恢复和实际 UI 路线；不能把来源自述直接写成程序通过。实际结果见 [NIGHT_WHITE_DEMO.md](NIGHT_WHITE_DEMO.md)。

首轮玩家测试关注：能否预测独立阻挡、区分观察与身体、辨认实体与预览、在安全处换组，以及是否愿意继续。14–20 分钟与 4/5 人理解等数字是来源设计目标，不是实测结果。
