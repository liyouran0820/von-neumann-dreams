# 午夜学院 · 映射：当前方案

本文件负责当前统一玩法规格与参赛表达。续写更新对应规则，以用户要求和原型证据为依据；实现检查写入 [MAPPING_DEMO.md](MAPPING_DEMO.md)，探索与淘汰依据写入 [MECHANIC_EXPLORATION.md](MECHANIC_EXPLORATION.md)，经过写入 `../log.md`。

状态：用户批准朋友的刻轨映射方案，保留全部五题和两座实验台，先用直接操控制作简单 Demo。用户明确忽略后续 `夜白映射_PRD.md`。编程、指令交换、双世界与影子不属于当前实现范围。

## 1. 定位

- 选题：The Midnight Academy。
- 形式：同一个可观察世界里的空间机制解谜。
- 玩家：一名纸灵，直接走路、推拉和连接纹章。
- 核心知识：相对变化、约束传递、局部与世界参照系、独立关系组。
- 规模：中央庭院、两个实验台、五道谜题；从开始就全部开放。

一句话规则：**连接两个物件，让它们沿各自刻轨一起前进或后退相同长度。做不到，就一起停下。**

## 2. 规则契约

| 规则 | 玩家可观察的后果 |
| --- | --- |
| 连接不对齐当前位置 | 不同起点可以建立关系，没有位置跳变 |
| 连通组共享本地位移 | 每个成员沿自身箭头前进同样格数，轴向可以不同 |
| 一格是统一长度 | 短轨两格对应长轨两格，不按行程百分比缩放 |
| 任一成员受机械约束，整组停下 | 远处端点、导环和实体阻挡可以传回本端；不积欠位移 |
| 断开只解除关系 | 当前位置保留，回位装置仍会正常工作 |
| 承载与映射独立 | 房间搬运子轨道，不等于子物件沿自身轨道移动 |
| 一组同时运动 | 根据共同运动的路径判断；相反运动可在世界坐标中抵消 |
| 冗余边不倍增运动 | 链、环、自连都只让每个成员移动一次 |

所有具有刻轨、箭头和活动纹章的物件都能互连。没有颜色配对名单、物体种类限制、连线数量限制或关卡专用施法权限。房间使用相同规则。人体、普通地面和装饰不能映射。

承载父子关系必须为树；映射父子关系或闭环合法。移动房间后重新计算所有后代的世界位置，即使后代不在映射组中，也检查它受到的约束。

## 3. 推拉、回位与撤销

1. 走到可达推拉处才能抓住；封闭物件可以映射，不能直接推拉。
2. 一名玩家只能持握一个物件。换手或走路先松开，旧组回位稳定后才能继续。
3. 手正在持握某个映射组时，压住该组回位；普通把手自身不会永久自锁。
4. 映射编辑暂停世界，保留持握。退出编辑先结算所有未被持握的回位组，之后才允许行走。
5. 桥从房间或玩家脚下撤走会造成失败，不能用“房间会掉下去”反过来把桥锁住。人体也不能充当回位刹车。
6. 撤回恢复本地刻度、全部连线、玩家位置、承载、持握、编辑状态和失败状态；重来恢复当前场景初值。
7. 完成要求机构到位、松手后稳定、玩家实际抵达出口，不检查参考连线形状或动作序列。

当前 Demo 用一次整格操作实现一次完整撤销；点地面自动寻路仍由连续普通走路步骤组成，每步可撤回。寻路只寻找可走路线，不自动推物件、连线或解题。

## 4. 由同一规则形成的场景

| 场景 | 玩家要发现的关系 | 保留的任务 |
| --- | --- | --- |
| 横竖刻轨实验台 | 两端都可驱动，各沿自己的箭头 | 自由连接、推拉和试端点 |
| 车厢实验台 | 子轨道属于移动的车厢 | 分别移动车与车内滑座 |
| 短尺开长门 | 重新连接可改变位置差 | 两格把手累积推动六格门 |
| 借来的轨道尽头 | 远处不能后退，可以制动本端 | 松手后保持桥接合并过桥 |
| 移动的房间，不动的天球 | 局部运动与承载运动可以抵消 | 房间到岸，天球留在固定导环 |
| 已经固定的东西，仍然能运走 | 固定局部刻度不禁止整体运输 | 保持桥接合，车厢运送标本 |
| 把整间学院搬过去 | 独立关系组分别处理保持与运输 | 房间与档案到岸、天球原地、桥稳定 |

没有知识点答题或新能力奖励。两实验台无判胜，不声称点击进去就掌握知识。提示由玩家主动逐层打开，不预填解法。

## 5. 表现与操控

- 中央庭院给出“从实验台开始”的入口，学馆同时开放。
- 点地面走路；点金色手印，或对应大按钮，走近并抓住。
- 推拉按钮分别表示沿固定箭头与反向；方向键也按刻轨轴向操作。
- 点两个青色纹章建立关系。可以在场景点纹章，也可用同名按钮。重复选择同一对断开；点击现有连线进入编辑并断开。
- 编辑期间清楚标出“世界暂停”和“结束映射”。
- 刻痕等间距、正向箭头与当前位置可见。房间、房间内轨道和固定世界导环分别绘制，避免视觉上把子物件强行带走。
- 端点与碰撞反馈指出实际抵住的物件；失败立即提供撤回与重置。
- Lucide 用于界面图标；纸灵、建筑与场景为原创 SVG。手机提供映射端点和推拉处的大按钮。

## 6. 参赛表达与验证标准

演示先连接横向与纵向滑块，观察同样长度与远端制动；再展示连接、断开、重连为何能用短尺开长门；用移动房间与固定天球解释参照系；最后在终局把保持桥梁与运输房间组织为两个组。

知识名称在发现后出现，世界规则本身承担教学。作品借鉴系统解谜的规则探索方法，不采用递归套箱、复制房间或现成作品关卡。当前朋友稿在本项目中有完整来源记录。

已验证：五题参考路线真实可达，第二题保留冗余关系、第三题另一端驱动、终局替代链与单格推进可行。详细规则与 UI 验收见 [MAPPING_DEMO.md](MAPPING_DEMO.md)。

仍需玩家体验：第一次是否知道目标、能否预测任意连线、是否理解房间与子轨道的区别、失败是否可解释、能否自行发现新用途。代码检查与设计纸面推演不代表趣味通过。
