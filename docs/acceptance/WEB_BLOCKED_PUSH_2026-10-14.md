# 贴住止挡后继续推动的验收

2026-10-14，按用户澄清更正代理对触发条件的误解。`WEB_STOP_SINGLE_CLICK_2026-10-14.md`记录上一次实现及其误解，不作为当前设计依据。本次实施前冻结以下条件，失败时修实现，不降低标准或改地图。

设计：能移动的一次推动只移动物体，即便本次恰好贴到止挡也不播放碰撞。已经贴住止挡后，一次朝该止挡的有效推动因受阻而不移动，立即播放压缩、回弹与接触闪光；反方向离开正常移动。两个世界分别判断，受阻侧立即反馈，另一侧仍可移动。
