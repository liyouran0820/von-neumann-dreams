# 单击止挡受力反馈验收

> 历史记录：本页把“刚贴住”也作为碰撞触发，是代理对用户意图的误解。同日已按用户澄清更正，当前条件见 [贴墙后推动验收](WEB_BLOCKED_PUSH_2026-10-14.md)。

2026-10-14，用户明确要求单击即可看出推力作用到当前世界的物体。本次在实现前冻结以下标准；这是用户对触发范围的追加，不因测试失败修改设计或降低标准。此前动作验收保留为旧提交证据。

设计：一次有效水平推动到达该方向止挡时，先完成一格移动，在接触位置播放既有压缩、回弹、闪光；已顶住止挡时同一次单击立即反馈，不要求第二次点击。两侧独立判断，反向离开止挡或未碰到止挡的正常移动不播放撞击。减少动态模式在位置更新时给出静态受力提示。

| 编号 | 冻结标准 | 状态 |
| --- | --- | --- |
| S01 | G1首次单击向右，夜箱从2到3即反馈，白箱从2到3正常移动；不需第二次输入，闪光不在移动途中提前出现 | PASS |
| S02 | 左/右到达止挡及已经受阻时，单击均反馈；白/夜两侧分别判断；每次只记录一次推动 | PASS |
| S03 | 离开止挡、轨道中段移动、无映射、桥映射及非法方向不误报碰撞；移动与blocked语义保持一致 | PASS |
| S04 | 到达后360ms精确归位；快速继续输入不残留；撤销/恢复/换关清理等待及播放中的反馈；观察/缩放不重播，减少动态模式没有位移/旋转/缩放 | PASS |
| S05 | 实际课程页面单击按钮即可触发；生成的web脚本和内联index.html同步；规则、已有掉落回归、构建、320px浏览器检查通过 | PASS |

## 执行结果

实施后追加被测源码、证据及失败/修复历史。临时证据保存在Git忽略的 `artifacts/web-motion/single-click/`。

- S01—S05 PASS：G1激活后只单击一次右推，夜箱2→3即出现压缩/接触环，白箱2→3无撞击；100ms途中不闪光、190ms接触、接触后65ms压缩和360ms归位均通过。已靠住、左右方向、白夜独立和每次一次历史通过。
- 现有blocked仍只表示未移动；新增hitStop表示本次推动抵达方向止挡或已受阻。反向离开止挡、轨道中段、非法方向和未映射不误触发。实际显示“止挡 · 推力已作用”，到达止挡与已受阻的文字区分移动结果。
- 连续推动、等待接触期间撤销/恢复/换关、观察/缩放、减少动态及既有掉落套件通过；66项自动检查、网页构建及空白检查通过。
- 实际课程页面首次单击按钮验证夜侧目标亮起、推力提示出现；320×740再次单击已靠住物体仍反馈，scrollWidth=320，浏览器脚本错误0项。同步生成web/generated/app.js和内联dist/index.html，核对内联脚本与网页脚本逐字一致。
- 失败/修复历史：首次回归发现已靠住物体的时间线等到下一动画帧才起算，改为该次输入即起算；尚在移动的物体仍等到接触。旧浏览器夹具在上一格移动尚未完成时立即按已靠住测试，且只等待360ms检查移动中的另一侧；调整夹具先完成190ms移动，再验证接触后的360ms归位，符合本次冻结S04。未缩短/删除反馈、改地图或降低标准，失败报告保留。
- 证据目录：`artifacts/web-motion/single-click/`；report.json、impact-regression.json、fall-regression.json均PASS；失败报告、unit-tests.txt、tested-source-sha256.json和首次单击/窄屏截图归档于同目录。验收页新增“执行单击验收”和“首次单击到达止挡”关键帧。
