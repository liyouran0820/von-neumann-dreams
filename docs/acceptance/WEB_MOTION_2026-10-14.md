# 网页动作反馈验收

2026-10-14，实施前冻结以下设计和验收标准。失败时修复实现，保留失败证据，不修改标准、地图、目标、出口或碰撞规则来取得通过。范围为当前网页课程及保留的原版对照，不计入 Godot 原生验收或真人体验验收。

## 功能一：止挡反馈

设计：有效水平推动受阻时，该侧实验箱朝推动方向压缩、回弹，接触侧出现金色闪光与短射线；整个过程 360ms 内回到精确位置与正常形状。两侧分别判断，移动侧只走一格。减少动态模式只保留短暂静态接触提示。

| 编号 | 冻结验收标准 | 状态 |
| --- | --- | --- |
| I01 | 同时移动无撞击；夜停白动、白停夜动、两侧都停分别表现正确，箱位及撤销历史与规则一致 | PASS |
| I02 | 左右碰撞方向相反；压缩、反向回弹、接触闪光可辨认；360ms 后位移/旋转归零、缩放归一、闪光消失 | PASS |
| I03 | 连续推动后仍归位；观察/选中/缩放不重播旧反馈；撤销/恢复/换关立即清理动作，不残留形变 | PASS |
| I04 | 减少动态模式不位移、旋转或缩放，仍有静态反馈；无映射/桥映射/非法方向/失败后输入不误触发 | PASS |
| I05 | 实际浏览器中夜侧、白侧、320px 窄屏可见反馈，无脚本错误、横向溢出；现有规则检查与构建通过 | PASS |

## 功能二：虚空掉落

设计：失去支撑立即进入既有失败状态，人物先短暂失衡，再加速落入虚空并淡出，约 900ms 完成；影子在失去支撑时消失。失败界面立即提供撤销/安全点恢复，动画不延迟失败判定、不自动复活。减少动态模式直接隐藏人物。

| 编号 | 冻结验收标准 | 状态 |
| --- | --- | --- |
| F01 | 桥上解除和换映射均触发一次掉落；预览、永久地面解除、撞墙/器材/无支撑方向被拒绝时不误触发 | 待执行 |
| F02 | 先失衡、后加速下坠、最后消失可辨认；人物不悬停在坑底；影子立即消失；900ms 内人物不可见 | 待执行 |
| F03 | 掉落期间及结束后观察/选中/缩放不重播；失败后行动禁用；撤销/恢复/重开/换关立即恢复正确人物位置、朝向、大小、透明度及影子 | 待执行 |
| F04 | 失败状态和恢复的完整箱位/映射/安全点/历史保持既有语义；不自动复活、不错误通关；减少动态模式直接隐藏且可立即恢复 | 待执行 |
| F05 | 实际浏览器中白侧和夜侧以及320px窄屏验证掉落和即时恢复，无脚本错误；现有五关路线、规则检查与构建通过 | 待执行 |

## 证据

实施和运行后按功能追加结果、被测源码、运行方式与失败/修复记录。临时截图和完整输出保存在 Git 忽略的 `artifacts/web-motion/`。

### 功能一结果

- I01—I05 PASS。实际 Three.js 场景采用独立验收时钟检查 65ms 压缩、162ms 回弹和360ms归位；同时移动、两种单侧受阻、两侧受阻、20次连续输入、左右方向、撤销/恢复/换关、观察/预览/缩放及减少动态均通过。白停夜动使用轨道范围内的独立箱位夹具，不修改关卡。
- 实际课程页面核对夜/白止挡文本、推动与观察/缩放；320×740无横向溢出（scrollWidth=320），窄屏关键帧可见接触反馈；浏览器脚本错误0项。
- 63项自动检查通过，含原版、历史光学和当前课程五关路线；网页构建及Git空白检查通过。
- 失败/修复历史：首次数值测试将正负零视为不同，并将同左端点路线误设为白停夜动；修正比较和合法箱位夹具，标准不变。首次浏览器场景抓取用错Three.js实例渲染钩子，改为场景渲染钩子。独立Chrome启动失败（path 1001），改用Codex内置浏览器。首次视觉复核发现接触闪光被箱体遮挡，增大/上移环与射线并保证绘制可见，随后复验通过。
- 完整输出与截图：`artifacts/web-motion/impact-report.json`、`impact-unit-tests.txt`、`impact-night-compress.png`、`impact-night-rebound.png`、`impact-day-left.png`、`impact-mobile-keyframe.png`及实际课程页面截图。产物保持Git忽略。
- 复现：先运行本地服务，再执行 `node tests/browser/verify-motion.mjs` 生成验收页，浏览器打开 `/generated/motion-harness.html`，点击“执行止挡验收”；下拉框可冻结关键帧。验收页和场景采集仅用于测试，生产页面不暴露调试状态。
