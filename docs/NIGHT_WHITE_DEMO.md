## 范围

用户明确采用《夜白映射：五关关卡设计》，并指定 GPT-6 Astra 制作。该模型完成新版游戏代码与规则测试；主代理核对来源、维护文档、执行本地 UI 试玩与 Git 收尾。

制作分支 `codex/night-white-demo`，版本 `0.4.0`。保留全部五关和十张源地图：入口庭院、回廊、断桥馆、双院与天文台。直接走路与远程操作；双世界固定配对、独立阻挡、一组名额、穿门和实体桥替换旧刻轨引擎。刻轨版本保存在 `f4705f7`。

## 操作

1. 点真实箱 / 桥，或“真实物件 · 预览”按钮，查看配对或另一世界的生成区域。
2. 点“激活映射”，左右推动按钮每次推动一格。箱 A 在两端分别受本地止挡影响。
3. 点“切换观察”查看另一世界。身体不移动；非身体视角禁用走路按钮，但仍能远程映射和推箱。
4. 点地面沿可达路线逐格行走，或用 WASD / 移动按钮。站在 P1 / P2 门座上，点“穿门”改变身体与观察世界。
5. 新桥预览保留旧映射；合法激活一次替换。虚影取消立即失去支撑，提供撤销和完整安全点恢复。
6. V 观察、方向键推动、E 激活、Q 解除、F 穿门、Z 撤销，均有等效按钮。使用 V 保留浏览器 Tab 的常规焦点导航。
7. “整关重置”恢复本关入口；“查看提示”主动展开三层提示。清除通关记录会回到 G1 初始态。

全部关卡可自由选择，正常通关也可顺序继续。提示不预填操作。存储键为 `night-white-five-v1-progress`，只保存通关地点，刷新恢复 G1 入口，旧版本数据保留。未实现完整退出存档或音量设置。

## 公开判胜

- G1：夜 A=3、白 A=5、身体到夜出口同时成立。
- G2：身体经白门和 P2 抵达夜出口；白门仅由白踏板控制。已经通过门后关闭白门仍可通关，不新增持续压板条件。
- G3 / G4：实际身体到夜出口，不检查示范顺序。
- G5：夜 A=6、白 A=4，同时身体脚底位于夜 `(15,2)` 或 `(15,3)`，支撑来自当前 C 虚影桥。岸边、白真实 C、只切观察或取消 C 均不能替代。

目标实时检查，离开目标即灭灯。G5 的 E 图标无独立地板。支撑先更新，再检查完成；通关后保持当前桥，不因演出解除映射。

## 灰盒边界

- 箱子与身体按格中心离散移动，寻路只找可走地面，不自动解题或穿门。固定桥全宽齐平支撑。
- 墙、玻璃、沟壑、踏板与桥是离散格约束；箱轨不作为身体步道。没有连续三维碰撞、摩擦、惯性、旋转或跳跃。
- 当前只有配置好的 A 真实对和固定 B/C 桥，未提供通用多箱、任意物件投影编辑器。
- 桥生成检查目标格阻挡并允许永久地面接触；它检验本版配置，不是通用三维实体穿插算法。
- 失败保留现场，玩家点撤销或恢复安全点，未制作自动坠落动画。箱子动作是即时状态步进，尚未制作缓动与音效。
- 映射预览是界面辅助，不单独写入撤销历史；操作前快照保留当时预览，恢复会带回完整双世界状态。
- 美术、连续操作手感、移动端地图辨识和发现过程仍需玩家测试与下一轮打磨。
