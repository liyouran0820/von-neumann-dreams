## 基线查验

官方macOS下载页和发布档案提供Godot4.7.2，已下载标准版并实际执行`--version`得到`4.7.2.stable.official.ed1daf0bf`。同版本模板已准备；源码4c2fbcb的干净arm64导出、严格签名及独立Metal窗口已通过P00验证。

设备为Apple M4、MacBook Air、16GB、macOS27.0 arm64，使用交流电；详情见`device_profile.json`。P00探针确认实际1920×1080与Apple M4 (Apple9) Metal渲染，证据见原生状态。

计划原图1672×941、哈希6550d6…在指定路径缺失；文件名搜索及47个同尺寸索引候选未发现同哈希。用户先后确认“将已上传图片确认为新的视觉基线”“可以，这个就好”。新基线为1000×572、哈希84949b…，原计划身份保留，不追溯改写原文。随后用户明确改单世界、Space点按切换和柔白色；见[交互修订](UI_INTERACTION_AMENDMENT.md)。旧原始文档不改写，新版V条目保留可读性和画质门槛。
