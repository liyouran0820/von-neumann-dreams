# The Midnight Academy：映射

> **一个动作改变两个地方；真正的魔法，是知道该让哪些东西一起改变。**

**文档类型：**机制与谜题设计稿 v1.0  
**范围：**一个核心机制、五个完整谜题、逐题静态验收，以及后续试玩的否决标准。  
**验收状态：**已完成规则推演、解法复核与主要旁路检查；尚未进行可玩原型或真人试玩。文中的“通过”仅指纸面设计成立，不代表趣味性已经得到验证。  
**语言说明：**数字、字母和公式供设计者核对。玩家面对的是房间、轨道、刻痕与运动，不需要输入公式或填写映射菜单。

## 1. 设计结论

保留“映射”这个方向，但必须把它从一个包罗万象的概念，收束为可以反复验证的规则：

> **把两个物体连起来。此后，一个沿自己的刻轨前进或后退多少格，另一个就必须沿自己的刻轨一起前进或后退多少格。做不到，就一起停下。**

连接时不对齐位置，断开后不撤销已经发生的位移。轨道可以装在地上，也可以装在另一个会移动的物体上。

这几句话足以产生本稿的五种体验：

1. 用两格行程的把手，把六格厚的门完全推开。
2. 把远处的轨道尽头，借来固定一座会缩回去的桥。
3. 让房间和房间里的物体都在移动，物体却停在世界中的原地。
4. 把一个已经被映射固定的物体，连同它的房间一起运走。
5. 把终局中的五个对象分成两个关系组，用一个短把手完成整座房间的搬迁。

这里的知识是：**相对变化、约束的传递、参照系，以及把一个问题重新组织成几个可独立处理的问题。**名称可以在玩家发现后出现，但不成为技能、配方或通关考题。

### 1.1 对先前构想的取舍

先前讨论最有价值的部分，是“玩家亲手改变问题的结构”。最需要收紧的部分，是把不同效果都称为映射，却没有给出相同的解释规则。

| 先前想法 | 本稿处理 | 原因 |
|---|---|---|
| 不同物体的变化可以关联 | 保留，限定为刻轨上的相同位移 | 玩家能预测任意一对合法对象的结果 |
| 房间也可以成为映射对象 | 保留，房间本身就是一个大型轨道物体 | 不增加第二套施法逻辑 |
| 映射“整个规律”或任意属性 | 暂不采用 | “规律”如何选取、什么算对应，目前都不明确 |
| 左右边界相连后可以传送 | 不纳入本稿 | 空间识别与传送不能从位移映射推出 |
| 自己连接自己会无限递归 | 否决 | “变化等于自身变化”不会凭空产生下一次变化 |
| 不告诉玩家到底映射什么 | 改为：操作对象明确，用途可以意外 | 不确定性应在解法上，不能长期停留在系统语义上 |
| 几百个对象自动压缩成一个模型 | 改为：玩家实际组织少量关键自由度 | 必须先证明小规模组合有趣，不能靠宏大描述代替谜题 |

**这一版的代价也很明确：**它暂时是一款空间机制解谜游戏，还不是能模拟生态、经济和信息系统的万能魔法。学科主题应建立在实际可玩的知识结构上；仅给机关换成不同院系的外观，不算实现跨学科玩法。

## 2. 核心规则契约

### 2.1 玩家做什么

- 走路，直接推拉够得着的物体。
- 用唯一的魔法，在两个带刻轨纹章的对象之间建立映射；也可以解除已有映射。
- 随时撤销操作或重置当前房间。

断开是编辑同一种关系，不是另外解锁一个“切断术”。没有翻转、缩放、存储、暂停时间等独立技能。编辑关系时的暂停是统一的思考与操作辅助，不参与解谜收益。

本稿不设置映射数量上限，不靠增加连线槽位推进游戏。单题最多需要三条线。

### 2.2 什么可以映射

一个合法对象具有：

1. 一条可辨认的刻轨。
2. 一支固定在轨道上的正向箭头。
3. 一个表示当前位置的活动纹章。

所有这样的对象都可以互相连接，没有按物体种类、颜色或关卡设置的配对名单。墙壁、普通把手装饰、玩家身体没有纹章，不能成为映射端点。哪些东西可选从第一次见面就清楚可见。

本稿只使用直线刻轨。一个对象只有一条可映射的运动轴，不弹出“选择位置、温度、颜色”的属性菜单。

### 2.3 一格是什么意思

一格是统一长度的刻轨步长，不是整条轨道的百分比。两格短轨与六格长轨相连，短轨走完两格，长轨也只走两格。

正方向由轨道箭头决定：

- 一条向右、一条向上：右移一格对应上移一格。
- 一条向右、一条向左：两者都沿箭头前进，世界中的运动方向相反。

玩家不能在连线上切换“反向模式”。方向差异已经存在于世界的轨道朝向中。

### 2.4 映射的五条判定

| 编号 | 规则 | 可观察的结果 |
|---|---|---|
| R1 | 连接不改变当前状态 | 两个物体相连时都不跳到新位置 |
| R2 | 连通的一组对象共享本地位移 | 一端前进一格，组内每个对象都沿自身箭头前进一格 |
| R3 | 整组只能完成共同合法的移动 | 任一成员遇到轨道尽头或实体阻挡，整组停住；不会欠下位移以后补发 |
| R4 | 断开只取消关系 | 已经取得的位置保留，之后各自响应自己的推拉、回位装置与碰撞 |
| R5 | 位移按各自轨道测量 | 轨道被房间整体搬走，不等于轨道里的物体自行走了一格 |

**双向而非遥控：**没有固定的输入端和输出端。手推、回位重锤、另一条映射都可能带来运动。障碍也能通过关系反过来限制看起来像“输入端”的对象。

**同时而非逐个：**判断一组运动是否合法，要看它们共同运动时的实际路径。不能先移动房间、判定内部物体撞墙，再移动内部物体。第三题依赖的就是共同运动产生的抵消。

**没有运动倍增：**A—B—C 仍然每个对象只走一格。额外连一条 A—C 不会让 C 走两格；闭环不制造运动。自连只是一条没有新增效果的恒等关系，界面可将它显示为冗余连接。

### 2.5 供设计者核对的表达

以 `qA` 表示 A 沿自身正向箭头的刻度。连接 A、B 后：

```text
ΔqA = ΔqB

因此，在连接保持期间：qA - qB = 常数
```

这个常数来自连接时的状态，不要求两者刻度相同。断开并重新连接，可以建立一个新的差值。这不是“保存位置”技能，而是连接不对齐位置的直接后果。

若房间 C 向右移动，房间内的滑块 S 沿向左的轨道移动，忽略固定的美术偏移：

```text
S 的世界位置 = qC - qS
```

若内部滑块 B 的箭头向右：

```text
B 的世界位置 = qC + qB
```

后两式是空间关系，不是新增的魔法。

### 2.6 普通世界规则也必须公开且统一

单一魔法不意味着世界没有碰撞、支撑和回位机构。它意味着这些条件不能只在某道题里临时改写。

- **刻轨是有定位卡齿的梦境机关。**没有驱动时，物体保持自己的本地刻度；没有惯性滑行。碰到障碍只会阻止运动，不会自动推动另一个未被驱动的物体，也不会自动释放内部滑块的卡齿。
- **默认没有自动复位。**需要回位的对象必须有持续可见的拉索和重锤；解除映射后，重锤仍然会拉动它。不能把断开当成冻结。
- **手推足以克服本稿的回位装置。**玩家可以推到一个刻度并按住。释放后，回位装置会拉动所有尚有合法退路的相连成员；不会因为另一个成员是把手就自动锁住。
- **映射不会因距离或承载物移动而断线。**线穿过墙面只是表现，不参与碰撞。每题的端点从总览视角均可辨认和选取，包括玻璃后的端点。
- **不能徒手抓取轨道物体离轨、堆叠或抛掷。**这是整款游戏的交互边界，不是遇到困难关卡才禁用。
- **施法编辑期间暂停运动。**可以在按住把手的状态进入编辑，完成接线与断线后再释放；无需抢在回位前操作。退出编辑后的无支撑回位会先稳定下来，再继续下一次移动，不能靠连续暂停“白嫖”一段行程。
- **失去支撑、夹住玩家等危险允许即时撤销。**本稿不要求牺牲角色、利用身体卡住回位机构或拼操作速度。

这里刻意选择了可预测的机关世界。尤其是“内部滑块不会碰墙后自动滑动”，必须通过卡齿外形和早期实验表达出来；否则玩家会合理地期待另一套物理规则。

## 3. 知识锁与教学结构

### 3.1 锁住的是玩家的推断，不是操作权限

所有施法操作从开始就可用。五个房间从中央庭院可进入，终局也可直接尝试；完成前四题不会给终局增加对象、线槽或属性。

推荐顺序由视线、路牌与入口距离引导。提前推导出后面的结论，应当允许提前完成对应房间。

也不把每个房间都包装成同样强度的知识锁：第一、三题偏重制造可观察的发现；第二、四题要求重新使用这些发现；终局检验组合。**在发现关试出正确操作是允许的，但不能据此宣称玩家已经掌握知识。**真正的验收是换了布局以后，玩家仍能预测、解释并主动构造解法。

| 阶段 | 玩家可能持有的旧认识 | 新的认识 | 迁移检验 |
|---|---|---|---|
| 入门 | 拉线只是远程按钮 | 双方实际共享位移和阻挡 | 换从另一端推动，仍能预测结果 |
| 谜题一 | 行程短，最多只能推这么远 | 不变的是相连期间的位移差 | 换一个起始刻度，仍能重新组织往返动作 |
| 谜题二 | 连线只负责让东西动起来 | 不允许的运动也会传递 | 换一侧轨道尽头，判断能挡哪个方向 |
| 谜题三 | 物体动了，就一定换了世界位置 | 相反的本地移动可以抵消 | 换成上下轨，仍知道该如何保持世界位置 |
| 谜题四 | 被固定的物体就不能运输 | 本地不动与世界不动是两回事 | 不解除约束，搬动整个参照系 |
| 终局 | 连得越多，控制越充分 | 有些关系必须分组，才能保留需要的运动 | 解释为什么静止组与运动组不能合并 |

### 3.2 入门实验台，不把答案写成课程

进入庭院前设置两个没有失败惩罚的小装置：

1. 一横一竖的等长滑块，均可手推。玩家相连后推动任意一端，观察另一端；把其中一端推到尽头，观察两者同时停下。
2. 一辆带内部短轨的车。先移动内部滑块，再移动整辆车。两者的刻痕分别固定在车内与地面上，使两种“移动”可区分。

只显示操作方式和受阻反馈，不出现“你可以利用端点制动”“接下来请抵消位移”等解法提示。刻轨方向、回位拉索与可选纹章不应该成为隐藏信息。

提示由玩家主动展开，按“提醒观察对象 → 提出可验证的问题 → 给出关键操作”分层。不能用自动高亮正确端点代替推理。

## 4. 谜题一：短尺开长门

**地点：**测绘学馆入口。  
**发现：**映射共享变化，不要求共享起点；玩家可以保留有用的前进，单独撤回把手。  
**预期体验：**“它只有两格长，但我的进展不必跟着它退回来。”

### 4.1 场景与目标

| 对象 | 轨道与初态 | 玩家能否直接推拉 |
|---|---|---|
| H：量尺把手 | 0～2，初始 0 | 可以 |
| D：厚石门 | 0～6，初始 0；正向使门离开通道 | 不可以，位于透明隔挡后的封闭滑槽 |

石门是平衡机关，没有回位重锤。门板必须退到第六格才完全露出一个可通行的门口；前五格仍与通口重叠。门的外形和刻痕清楚展示所需距离。

```text
可操作侧                       封闭门槽
H：0──1──2       可映射        D：0──1──2──3──4──5──6
                                                      通口完全露出
```

目标：D 到达 6，玩家通过通口。全部关键对象只有 H、D。

### 4.2 可复核解法

| 步骤 | 操作 | H | D | 当前映射 |
|---|---|---:|---:|---|
| 0 | 初始 | 0 | 0 | 无 |
| 1 | 连接 H—D，推动 H 两格 | 2 | 2 | H—D |
| 2 | 断开，将 H 单独拉回起点 | 0 | 2 | 无 |
| 3 | 重连 H—D，再推两格 | 2 | 4 | H—D |
| 4 | 断开，将 H 单独拉回起点 | 0 | 4 | 无 |
| 5 | 重连并再推两格 | 2 | 6 | H—D |

重连时 D 不跳回 0。只要保持连接，把 H 拉回来就会把 D 也拉回来，因此关键并非多推几次，而是决定哪一段运动应该被共享。

### 4.3 发现路线与误导边界

第一次推到头时，石门确实前进了两格；不是出现“力量不足”文字。回拉会把成功撤销，断开后再回拉则不会。反馈足够局部，玩家可以用一两次实验区分假设。

三级提示：

1. “把手回来时，门为什么也回来了？”
2. “哪一段动作需要共享，哪一段不需要？”
3. “门前进后，先断开，再把把手拉回。”

### 4.4 自我验收

| 维度 | 实际检查 | 结论 |
|---|---|---|
| 公平性 | 仅使用 R1、R2、R4；门无回位装置，停留状态可提前观察 | 通过 |
| 可发现性 | 失败动作会完整退回两格，给出“回程也被复制”的证据；不要求发现隐藏端点 | 纸面通过，需确认玩家会尝试断开 |
| 意外歧义 | 若一格被理解成百分比，解法就不成立；因此两轨使用相同间距的刻痕 | 已消除定义歧义 |
| 非预期解 | 每次只推一格、在不同刻度重连都有效；接受。自连和重复连线不能增加位移 | 通过，允许多种等价操作序列 |
| 同一核心规则 | 没有存储术、棘轮特效或“第三次推动开门”的脚本判定 | 通过 |
| 失败恢复 | 任何中间状态都可撤销，也可以按原理继续积累 | 通过 |

**趣味判断：保留为早期题，不作为宣传用的核心惊喜。**三次行程足够，不扩成十次。若玩家一眼解出，这是成功的入门，不应靠增加劳动补足时长。

## 5. 谜题二：借来的轨道尽头

**地点：**建筑学馆的回缩桥。  
**发现：**连接也能传递“不能再退”的限制。  
**预期体验：**“我没有把东西搬过去挡住桥，而是把远处的退路借走了。”

### 5.1 场景与目标

| 对象 | 轨道与初态 | 物理条件 |
|---|---|---|
| H：手推把手 | 0～3，初始 0 | 玩家唯一可以直接驱动的对象 |
| G：抽板桥 | 0～3，初始 0 | 正向伸出；可见重锤持续拉向 0；到 3 才完整连接两岸 |
| B：铜滑块 | 0～1，初始 0 | 在透明壁龛内，不能徒手触及；无回位装置 |

任务是恢复一条**松手后仍稳定连接的通道**，并走到对岸。持续扶着把手不算完成，抢在桥缩回前跳过去也不满足修复目标。桥的两端有明确的接合结构，稳定状态从世界中可见。

B 的“0 端”是实物轨道尽头，不是零刻度对应一种特殊魔法。相连以后若要沿负方向走，B 没有空间。

### 5.2 可复核解法

1. 连接 H—G，把 H 从 0 推到 3，并保持按住；G 伸到 3。
2. 在暂停的映射编辑中，把 G 与仍在 0 的 B 相连。
3. 解除 H—G，然后松手。
4. G 的重锤试图让 G 后退；这要求 B 从 0 后退，违反轨道边界，因此 G—B 都不动。
5. H 已经自由，玩家离开操作位，沿稳定的桥前往对岸。

最终：`H=3，G=3，B=0；仅 G—B 保持连接。`

它不是单向的神奇锁：G 若还存在正向空间，本可以带着 B 一起前进。但此时 G 已经在 3 的末端，正向也没有空间，所以这一对恰好被两个不同方向的端点完全固定。

### 5.3 反例与发现路线

- 一开始就连接 H—G—B 再推：B 只能走一格，整组提前停住。这正是有用的失败证据。
- 只解除 H—G：桥照常退回；断开本身不会冻结重锤。
- 把 B 先推到 1，再与 G=3 相连：重锤仍能把它们拉到 `G=2，B=0`，停得太早。轨道的哪一端很重要。
- 把 G 留在 H=3 上：重锤可以把 H 一起拉回来；普通把手不是天然刹车。

三级提示：

1. “铜滑块到了轨道尽头时，另一端还能继续走吗？”
2. “桥想往回走的时候，能否让另一个对象没有同样的退路？”
3. “先把桥推出去，再连到仍在起点的铜滑块。”

### 5.4 自我验收

| 维度 | 实际检查 | 结论 |
|---|---|---|
| 公平性 | 回位重锤持续可见；入门已展示阻挡会反向影响输入端；编辑可以暂停 | 通过，不要求手速 |
| 可发现性 | 提前连 B 会让桥在一格处停住，同一现象可被重新解释为工具 | 通过，有针对核心的失败反馈 |
| 意外歧义 | 区分“没外力所以停着”与“有重锤所以复位”；本题不得把 H 做成自锁摇柄 | 已明确，表现仍须实测 |
| 非预期解 | 不拆 H—G，保持三者连接也能稳定，允许；用一格刻度分步搬动不能让无人支撑的桥稳定 | 通过 |
| 身体卡桥旁路 | 回位拉索与 B 均在封闭区；桥向岸内抽回，桥面上的人不能堵住其回缩路径；胜利要求持久接合 | 纸面排除，须验证桥面与角色的空间接触 |
| 同一核心规则 | 固定来自 R3 的端点限制，G、B 均没有“刹车”专属属性 | 通过 |
| 失败恢复 | 重锤只把状态拉回，玩家有安全操作台；掉落可撤销 | 通过 |

**趣味判断：保留。**与第一题形成关键反差：第一题断开能保留进展，第二题断开却会丢失进展。区别来自明确的外力，而非魔法改了规则。

## 6. 谜题三：移动的房间，不动的天球

**地点：**天文学馆的滑移观测室。  
**发现：**相同的本地变化，可以在世界中互相抵消。  
**预期体验：**“我要移动的不是天球；我要让房间从它身下滑过去。”

### 6.1 场景与目标

| 对象 | 轨道与初态 | 正向与参照物 |
|---|---|---|
| C：观测室 | 0～3，初始 0 | 向右，轨道固定在地面 |
| S：天球滑座 | 0～3，初始 0 | 向左，轨道固定在 C 内 |

S 的细轴穿过一个固定在建筑上的狭窄导环。导环阻止细轴左右移动；C 的墙面有足够长的敞口，可以从导环外侧滑过，不会碰到导环。C 与 S 均有可直接操作的推拉处。

房间地板移动到 C=3 时，房门与对岸平台接合，玩家可以离开。S 必须始终留在导环允许的世界位置。

```text
建筑：                    固定导环 ○  世界位置 0
                                   │
房间 C：              [       天球 S       ]   C 正向 →
房内轨道：                 ← S 正向

C 前进：想把整个房间及 S 向右带走。
S 前进：相对于房间向左移动。
```

### 6.2 为什么两个单独动作都失败

- 只推动 C 向右：S 的卡齿保持本地刻度，细轴试图向右穿过导环实体，C 停住。
- 只推动 S 沿箭头向左：细轴直接撞导环另一侧，S 停住。

不要把这两次失败呈现成“机关没有电”。应清楚看到哪处发生抵触，以及未驱动的内部滑座仍停在自己的刻痕上。

### 6.3 可复核解法

连接 C—S，推动任意一端沿正向前进三格。

| 状态 | qC | qS | 天球世界位置 `qC-qS` |
|---|---:|---:|---:|
| 初始 | 0 | 0 | 0 |
| 第一格 | 1 | 1 | 0 |
| 第二格 | 2 | 2 | 0 |
| 接合 | 3 | 3 | 0 |

每一小段运动中天球都不离开导环中心；不是先撞进去，再被传送回来。观测室从静止的天球下方移动，最后形成可通过的连接。

三级提示：

1. “天球的刻痕画在哪个物体上？”
2. “房间向右一格，天球又在房间里向左一格，它相对导环在哪里？”
3. “连接房间和天球滑座，让它们同时沿各自箭头前进。”

### 6.4 自我验收

| 维度 | 实际检查 | 结论 |
|---|---|---|
| 公平性 | C 的地面轨道、S 的房内轨道均完整可见；两者箭头相反；导环与建筑连接明确 | 通过，前提是场景确实能读清父子关系 |
| 可发现性 | 两次单独推动分别撞向导环两侧，使“两个影响方向相反”可观察；入门车展示过参照物 | 纸面通过，列为重点试玩项 |
| 意外歧义 | 普通物理直觉可能认为房间会自动从滑座下滑过；统一卡齿规则阻止这种无指令滑动 | 已定义，但有显著认知风险 |
| 非预期解 | 先动 C 或先动 S 都不能开始；反复断接不改变位置；从 S 驱动整组同样合法 | 通过 |
| 知识锁强度 | 只有两个端点，玩家可能未经推理就尝试唯一的一对连接并通过 | 单独不足以验证掌握；定位为发现关 |
| 同一核心规则 | 只用 R2、R3、R5；没有“抵消术”、特殊导环识别或穿模许可 | 通过 |
| 中间过程 | 任意相同比例的共同位移都保持世界位置 0，不依赖只检查终点 | 通过 |
| 失败恢复 | 单独推动只受阻，不破坏细轴；撤销可恢复所有状态 | 通过 |

**趣味判断：核心候选，但不是无条件通过。**如果玩家理解映射，却持续认为内部滑座理应自动让位，问题在世界运动语法。应先改善卡齿、推拉反馈和入门实验；若仍无法建立一致预期，就否决该题，不能用旁白硬宣布玩家直觉错误。若只是试连后通关，要让玩家在后续变式中证明理解，不靠加入一排无用端点来人为扩大猜测空间。

## 7. 谜题四：已经固定的东西，仍然能运走

**地点：**自然史馆的标本渡运车。  
**发现：**映射固定的是本地变化；承载它的房间仍然可以移动。  
**预期体验：**“标本还在替我撑住桥，但我可以把它所在的车厢一起开走。”

### 7.1 场景与目标

| 对象 | 轨道与初态 | 直接操作条件 |
|---|---|---|
| C：运输车厢 | 0～4，初始 0；正向向对岸 | 车厢有随行推拉处，玩家可直接驱动 |
| S：标本滑座 | 车内 0～2，初始 0；正向与 C 同向 | 可观察、可映射，不可离轨取走 |
| G：抽板桥 | 0～2，初始 0；到 2 完整接合 | 入口处可以直接推出并按住；有持续回位重锤 |

本题没有 H。G 的推拉处就是 G 自身的一部分，不是一个额外可映射对象。

G 是从侧面抽入车道下方的宽桥面。伸出两格后，覆盖整个渡运段；回缩时从车底抽走支撑，不会被车厢侧壁顶住。两岸的固定导轨规定 C 的方向；桥板不是 C 的参照轨道，也不会在回缩时把 C 一起横向搬走。

目标：C 到达 4，标本停在车内 0，与对岸接收架对齐；G 保持接合。标本接收架的实际位置就是 `世界位置=4`，没有隐藏数值校验。车厢终端挡块与接收架共同确定最后姿态。

### 7.2 可复核解法

1. 直接将 G 推到 2，保持按住。
2. 连接 G—S。此时 `G=2，S=0`。
3. 松开 G：G 想退，要求 S 从 0 后退，被 S 的轨道尽头阻止。
4. 直接推动 C 从 0 到 4。S 一直处于车内 0；G 也一直处于 2。
5. 车厢到岸，标本抵达接收架，桥仍稳定接合。

| 状态 | qC | qS（车内） | 标本世界位置 `qC+qS` | qG |
|---|---:|---:|---:|---:|
| 桥被固定 | 0 | 0 | 0 | 2 |
| 途中 | 1 | 0 | 1 | 2 |
| 途中 | 3 | 0 | 3 | 2 |
| 到达 | 4 | 0 | 4 | 2 |

S 的本地正向也无法运动，因为那会要求 G 超过 2。于是 S 确实被完全固定在车内；它仍随 C 改变世界位置。

### 7.3 为什么不是“先取消固定再搬走”

断开 G—S，重锤就会回缩桥面，运输失去支撑。把 G 改连 C 也不行：G 已在正向尽头，C 一旦尝试前进就会被同组阻挡。

解法要求区分“车厢这个对象”与“车厢里的对象”，而不是发现另一种能抵消约束的道具。

三级提示：

1. “被固定的是标本在哪条轨道上的位置？”
2. “车厢前进时，标本在车厢里的刻度改变了吗？”
3. “让标本继续连接桥，只推动车厢。”

### 7.4 自我验收

| 维度 | 实际检查 | 结论 |
|---|---|---|
| 公平性 | 标本轨道明确安装在车内；终点接收架与车内 0 的位置对应可见；目标要求桥稳定 | 通过 |
| 可发现性 | 上题展示“本地在动、世界不动”；本题提供其反面，车内刻痕持续可见 | 通过，但需观察是否被当成重复题 |
| 意外歧义 | 若连线随运输拉断，或复制标本的世界位移，解法都失败；R5 与不按距离断线已统一规定 | 通过 |
| 非预期解 | G—C 会锁住运输；断开 G—S 会失去支撑；徒手取走标本不在全局操作集合中 | 通过 |
| 几何旁路 | 车厢不能替桥挡住回缩，因为桥面从其下方撤走；早运 C 再开桥也会先失去支撑 | 纸面通过，桥板接触关系必须白盒复核 |
| 同一核心规则 | 没有“固定解除”“运输豁免”或房间专属魔法；G—S 的约束全过程成立 | 通过 |
| 失败恢复 | 起点有安全停靠面，支撑丢失可撤销，不把标本永久摔坏 | 通过 |

**趣味判断：保留为短题。**第三题需要构造抵消；这题需要意识到根本不必解除约束。如果玩家已经提前推导出它，应让其迅速通过，不再叠加重复路程。

## 8. 终局：把整间学院搬过去

**地点：**午夜学院中央大礼堂。  
**发现：**控制一个复杂系统，关键是让该动的东西一起动，让不该动的关系独立保持。  
**预期体验：**“这些机关没有各自的答案。我只需要一个运动组和一个固定组。”

终局不是四扇门各考一道旧题。桥、房间、固定天球与随车档案必须在同一次搬迁中同时满足条件；短行程把手则迫使玩家维持已经组织好的结构。

### 8.1 场景与全部状态

礼堂是一间能横移的房间 C。其内部有两个独立滑座：天球 S 的细轴仍穿过建筑上的固定导环；档案柜 B 则需要随房间到达对岸。房间前方缺少支撑，需要从侧面推出一整块宽桥面 G。

玩家站在安全操作台，只能直接推拉 H。C、S、B、G 均在透明封闭区，始终可映射、可观察，但不能徒手推动。

| 对象 | 范围 | 初始 | 正向与参照 | 其他条件 |
|---|---|---:|---|---|
| H：短行程把手 | 0～2 | 0 | 向右，地面轨道 | 唯一直接输入 |
| C：整间礼堂 | 0～6 | 0 | 向右，建筑固定导轨 | 到 6 时房门接上出口平台 |
| S：天球滑座 | 0～6 | 0 | 向左，安装在 C 内 | 世界位置被固定导环约束为 0 |
| B：档案滑座 | 0～1 | 0 | 向右，安装在 C 内 | 无重锤；需随车抵达对岸接收架 |
| G：宽抽板桥 | 0～2 | 0 | 从侧面伸入车道，建筑固定轨道 | 重锤拉向 0；只有 2 才提供完整渡运支撑 |

两条内部轨道处于不同高度，不互相碰撞。C 的敞口允许它从导环外侧滑过，和第三题相同。G 的桥面长度覆盖整个六格渡运段，自己的伸出方向与渡运方向垂直，因此“伸出两格、支持六格行程”不是映射缩放。

桥板抽回时从房间下方撤走，不与房间侧壁或导环相撞；房间不能成为阻止回缩的楔子。途中失去支撑即失败并可撤销。

```text
安全操作台                      大礼堂 C：正向 →
H：0──1──2                     ┌────────────────────┐
                               │ S：正向 ←  固定天球 │
                               │ B：正向 →  随车档案 │
                               └────────────────────┘
                                            固定导轨：0 → 6 → 出口

G：从侧面抽入的整块桥板，0 → 2；重锤持续使其退回。
```

**胜利状态：**房间 C=6，与出口接合；S 的世界位置始终保持 0；B 停在车内 0，随 C 到达世界位置 6 的档案接收架；G 在无人手持的情况下保持 2。

场景可以宏大，但有效变量只有这五个。书架、窗框与装饰若随房间移动，应明确是同一房间的固定组成部分，不伪装成几十个需要逐个检查的机关。

### 8.2 四种合理尝试为什么失败

| 尝试 | 失败原因 | 玩家获得的证据 |
|---|---|---|
| H—C，直接推房间 | 桥未接合；即便桥已就位，天球仍会撞导环 | 要处理支撑，也要处理内部参照物 |
| H—G，把桥推出后断开 | 重锤把桥拉回 | 需要一个独立保持的关系 |
| 用 S 固定 G | S 需要随 C 在房内向左移动，但 G 已在正向尽头 | 正确的刹车对象不能占用需要运动的自由度 |
| 把所有东西连成一组 | G 无法再前进，整组不能前进 | 更多连接会消灭需要的运动 |

失败应指向具体受阻对象，不能只显示一句“无法操作”。不过反馈只指出发生的接触或端点，不推荐替代连法。

### 8.3 完整解法

#### 阶段 A：建立独立的支撑组

1. 连接 H—G，将 H 从 0 推到 2，按住；G 到 2。
2. 连接 G—B，此时 B 仍为车内 0。
3. 断开 H—G，松手。B 的负向端点阻止 G 回缩。
4. 将自由的 H 拉回 0。

此时：`H=0，C=0，S=0，B=0，G=2`，仅有 G—B。

#### 阶段 B：建立运动组

5. 连接 C—S，使房间向右与天球在房内向左共享位移。
6. 连接 H—C。此时共有三条线：H—C、C—S、G—B。

```text
运动组：H — C — S       支撑组：G — B

同组本地前进相等         两个端点共同阻止本地运动
```

#### 阶段 C：保留结构，分三次推进

7. 把 H 从 0 推到 2：C=2、S=2。天球仍在世界位置 0；B 仍在车内 0，但已随房间来到世界位置 2。G 不动。
8. 只断开 H—C；保留 C—S 与 G—B。将 H 拉回 0，再接回 H—C。
9. 再推两格，得到 C=4、S=4。重复一次把手回程。
10. 最后推两格，得到 C=6、S=6。房间接上出口，档案到岸，天球仍在原处，桥仍保持接合。

### 8.4 全过程状态核对

| 检查点 | H | C | S | B | G | 天球世界位置 `C-S` | 档案世界位置 `C+B` |
|---|---:|---:|---:|---:|---:|---:|---:|
| 初始 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| 支撑组完成，把手已回程 | 0 | 0 | 0 | 0 | 2 | 0 | 0 |
| 第一次推进 | 2 | 2 | 2 | 0 | 2 | 0 | 2 |
| 第一次把手回程 | 0 | 2 | 2 | 0 | 2 | 0 | 2 |
| 第二次推进 | 2 | 4 | 4 | 0 | 2 | 0 | 4 |
| 第二次把手回程 | 0 | 4 | 4 | 0 | 2 | 0 | 4 |
| 第三次推进／完成 | 2 | 6 | 6 | 0 | 2 | 0 | 6 |

每次把手回程都不改变另外四个对象。桥的回位冲动始终被 B 的本地端点阻止；B 随房间运输不改变它的本地刻度，因此不要求 G 跟着移动。

### 8.5 为什么这个解确实需要理解结构

本布局的持续推进阶段有三个必要条件：

1. 导环要求 `ΔC-ΔS=0`，所以 C 与 S 必须共同前进。它们不能单独开始一步合法运动。
2. 桥必须保持 G=2；它不能加入正在正向移动的组，否则上界会挡住整组。
3. H 是唯一可直接驱动的对象，需要参与运动并反复回程。它不能同时承担固定桥的角色。C、S 也需要运动，剩下能独立约束桥的对象是 B。

因此，预期解不是随意挑出了 B，而是玩家推导出：**B 的本地刻度可以保持不变，同时在世界中完成运输。**

这只证明关键关系分工，不宣称完整操作序列唯一。H—S—C 与 H—C—S 等价；可以用一格行程慢慢推进，也可以在支撑组中保留冗余连接，只要不阻止必要运动。符合规则的解都应被接受。

三级提示：

1. “房间运动时，哪些对象必须改变自己的刻度，哪些必须不变？”
2. “档案在房间里的刻度不变，还能抵达对岸吗？”
3. “让桥与档案形成一组；让把手、房间、天球形成另一组。把手回程时只断开它自己。”

### 8.6 自我验收

| 维度 | 实际检查 | 结论 |
|---|---|---|
| 公平性 | 所有对象均沿用前题外形与规则；无新端点类型、时间限制或后期权限 | 通过 |
| 可发现性 | 失败可定位到支撑、导环或轨道尽头；五对象可同时观察；前题分别提供可迁移经验 | 纸面通过，需确认玩家能把“静止组”单独识别出来 |
| 意外歧义 | G 的两格伸出与 C 的六格行程方向垂直；B、S 各有独立车内轨道；桥不是 C 的参照物 | 已明确，白盒必须忠实展示 |
| 顺序与中间态 | 先稳住 G，再组织 C—S，最后连接 H；每次回程都只释放 H | 状态表通过 |
| 过度连线 | 全连接会因 G 的正向上界而停住，不产生多次推动或“更大力量” | 通过 |
| 直接控制旁路 | 玩家只能接触 H；不能徒手移动 C、S 或把 B 搬到桥边 | 通过，属于可见空间条件 |
| 提前运输旁路 | G 未完全接合时 C 无法安全进入渡运段；S 也不能离开导环允许位置 | 通过 |
| 卡住回位旁路 | 使用侧向抽出的支撑桥，避免“让礼堂顶住关门”的替代解 | 纸面通过，仍需空间验证 |
| 同一核心规则 | 支撑依赖 R3；抵消依赖 R2、R5；把手回程依赖 R1、R4；档案运输依赖 R5 | 通过，无终局专属魔法 |
| 失败恢复 | 错误连接可拆除；失去支撑可撤销到上一步；不要求重玩整个章节 | 通过 |

**趣味判断：值得做成主验证关。**最后的洞见应当发生在分组完成时，后续三次短行程只是兑现计划。若玩家已经理解却觉得操作冗长，应改善连线编辑与回程交互，不应再给它增加更多对象。

## 9. 本轮设计验收记录

### 9.1 已进行的核查

这次验收采用纸面状态推演与反例检查，未声称完成程序穷举或真实碰撞验证：

- 对五题分别列出初态、目标、直接操作权限和环境约束。
- 顺着所述解法核对每一步状态与轨道范围。
- 检查断开、重连、反向驱动、全连接、冗余连接与自连。
- 检查所需效果能否从 R1～R5 推出，而非由对象名称决定。
- 检查“先把目标搬好”“松手即可保持”“用身体或运输物卡住门”等旁路。
- 将不能纸面确认的可发现性与接触几何，明确保留为待验证项。

### 9.2 被否决或修正的草案

| 草案问题 | 为什么不合格 | 本稿修正 |
|---|---|---|
| 自连后自动产生无限运动 | 需要额外的触发与重复规则；恒等映射本身不能推出 | 不把递归当作现有效果 |
| 断开任何目标都能固定它 | 否定回位外力，也让借用障碍失去意义 | 区分平衡机关与可见回位机构 |
| 再次连接会把位置对齐 | 会破坏短行程累积，并让连接本身成为瞬移 | 全局规定连接不跳变 |
| 终局先开桥，之后随便搬房间 | 可绕过维持支撑的结构问题 | 桥有持续回位，必须在运输期间保持稳定 |
| 用下降闸门阻挡终局运输 | 礼堂可能直接顶住闸门，替代预期支撑关系 | 改为从车底侧向抽出的桥板，回缩方向不被礼堂挡住 |
| 后期突然允许移动房间 | 等同于隐性解锁对象类型 | 从入门实验起就展示可移动承载物，房间始终有相同纹章 |
| 暂停施法后抢一帧绕过回位 | 把知识锁变成操作漏洞 | 编辑结束先结算无支撑回位，不允许逐帧偷运 |

### 9.3 对“一个机制”的反向审查

本稿没有把一切复杂度都消灭。它仍要求玩家理解三类普通世界条件：**轨道边界、外力回位、物体嵌套。**如果这些条件全在同一房间首次出现，即使只有一个按钮，认知负担依然会很大。

因此，单机制的验收不能只数技能图标，而应问：

> 玩家看见一对从未连接过的合法对象，是否能仅凭已经掌握的规则，预测一次推动的结果？

如果答案是否定的，要减少语义或改善世界表达，不能靠增加百科条目来维持“系统很深”的印象。

本稿暂时不加入旋转、液位、温度、颜色、生命数量和周期边界。未来若要加入，必须先定义与现有刻轨一致的变化单位、边界和参照物，并证明不需要对象专属解释。不能仅因为某个组合看起来酷，就把它纳入当前规则。

## 10. 下一轮试玩如何否决这套设计

下一步优先验证第一题、第三题和终局：第一题验证变化与重连，第三题验证最危险的参照系语义，终局验证组合是否真正产生了推理。

以下是建议的测试标准，不是本轮已经取得的结果。

| 测试 | 观察方式 | 需要返工的信号 |
|---|---|---|
| 任意配对预测 | 给两个没见过的合法对象，先问移动后会怎样，再允许操作 | 多名玩家都必须试出来，无法解释预测依据 |
| 失败是否提供证据 | 玩家受阻后，说出是什么挡住了谁 | 只能说“这个组合不行”，不知道限制来自哪里 |
| 连接与位置差 | 将第一题的起始刻度改变，不再从 0 开始 | 玩家只会复述“三推两拉”，无法适应新初态 |
| 参照系迁移 | 将第三题换成上下移动，并调换观察角度 | 玩家记住了横向动作，却不理解世界位置为何不变 |
| 终局分组 | 玩家完成后，指出为什么 G 不能和 C 同组 | 通过了却解释不出，或纯靠遍历连线碰巧完成 |
| 自由解法 | 记录不同链形与不同回程策略 | 为保护标准答案，需要按名称禁止合法连接 |
| 教学成本 | 观察卡住时是否需要解释新的隐藏规则 | 同一道题要补充两条以上先前没有世界证据的约定 |
| 操作与思考比例 | 记录玩家说出解法后还需要多久才能兑现 | 思路已经完成，剩下的大部分时间只是重复接线 |

建议先找 6～8 位未看过设计稿的玩家进行观察，逐次修正后再扩大测试。这个人数只用于早期找问题，不用于宣称统计有效的好评率。

对知识锁尤其要区分三种情况：

- **不会操作：**界面或可选对象表达有问题，不算谜题难度。
- **理解规则但没想到组合：**这是本设计想保留的思考空间。
- **提出了合理解法却被额外规则否决：**规则或关卡有问题，应优先修设计。

若第三题持续依赖冗长解释才能成立，或终局最有效的策略是枚举连线，那么应缩减或否决当前版本。不能因为“映射”这个概念有吸引力，就降低对可预测性和实际游玩质量的标准。

## 11. 叙事与呈现落点

午夜学院不必告诉玩家自己学会了“高等魔法”。让空间本身回应：一座没有支柱的桥借用了远处的尽头；一间观测室从静止的星球下经过；一本被固定在柜里的档案随着整座礼堂来到彼岸。

解完之后，可以在笔记里留下玩家刚刚验证的短句：

> “相同的变化，不要求相同的起点。”  
> “不能移动，也是一种能传递的限制。”  
> “说一个东西没有动之前，要先说清它相对于什么。”

这些笔记不解锁能力，也不自动给未来物体贴上答案标签。它们记录玩家已经做到的事。

这一版需要证明的产品命题只有一个：**同一种简单的关系，能否让玩家亲手把看似互相冲突的空间条件，组织成一个自己能够控制的系统。**
