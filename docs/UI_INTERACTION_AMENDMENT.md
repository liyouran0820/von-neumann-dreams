# 单世界观察与白侧配色修订

本文件记录用户对视图和操控的明确修订，负责说明与来源计划的差异。续写保留批准经过及实现范围；原文快照不改写，实际检查写入网页试验记录和阶段报告。

## 已批准的交互

2026-10-13，用户要求“每次只显示一个世界”，随后明确“用户不用按住空格切换，按一下切换，然后按一下切换回来”。最终采用点按切换，替代最初提出的按住观察，也覆盖开发计划 v1.2 的固定左右双视图与 Tab 焦点操作。

- 进入关卡显示身体所在世界；每次点按 Space 切换观察世界，松开后保持，再按一次切回。
- 屏幕按钮提供相同点击切换。键盘重复事件不连续切换；弹窗和文字输入时不触发场景快捷键。
- 每次只呈现一个世界，两个世界使用一致的镜头尺度和取景。切换终止当前自动行走，失焦不改变已选观察世界。
- 观察不移动身体、不占玩法撤销历史；在另一侧仍能选择真实物件、激活映射和遥控箱子。走路和 F 穿门需回到身体视角。
- 成功穿门后视图跟随身体；撤销/恢复按完整快照恢复，关卡重开回到初始身体视角。
- 标题同时标明当前世界与身体所在侧；屏幕外另一端的推动结果仍在操作反馈中显示。

## 已批准的视觉方向

用户反馈白侧不清楚且并排明暗对比不舒适，随后要求“白天还是以白色为主色调吧”。白侧采用柔白石面、浅冷灰墙体、较深的侧面与沟壑，低曝光柔光保留轮廓；机关用金铜色区分。夜侧采用柔和蓝灰。材质和光照数值属于网页试验，不代替原生 U03 的质量 profile。

## 基线与落地边界

新目标基线为 `native-demo-1.2-single-world-space-toggle-2`，只修订视图布局、观察键和上述配色方向。来源哈希、五关坐标、规则、尺寸、性能和可访问性要求保持来源约束；V01/V04/V11 期望已同步。

本轮已在网页 Demo 实现并验证。Godot P00 空工程仍保留原始双视口启动结构；原生 P02/U 阶段需按本修订实现交互与呈现，当前不据网页结果标记原生通过。旧 P00 报告继续关联原被测提交和旧基线。
