# 午夜学院 · 刻轨映射 Demo

本文件负责本次 Demo 的实际范围、操作、代码职责、验证与限制。续写以当前源码和实际检查为依据；规则规格进入 [FINAL_GAME_PLAN.md](FINAL_GAME_PLAN.md)，流水事实进入 `../log.md`，不把体验推断写成验证结果。

## 范围

当前分支 `codex/correspondence-demo`，版本 `0.3.0`。按照朋友映射稿实现中央庭院、两个入门实验台及全部五道谜题。直接操控替换旧编程界面。忽略用户后续明确弃用的 `夜白映射_PRD.md`。

场景是俯视浅立体 SVG 白盒。相同的引擎处理所有物件，物件种类只影响美术与数据；没有关卡专用的正确配对列表。所有学馆可自由进入。

## 操作

- 点地面：沿当前可达路径走过去；点出口也会实际逐步行走。
- 点金色手印或推拉处大按钮：走近再抓住。仅抓住可达的一件物件。
- 沿箭头推 / 反向拉：全组沿各自刻轨变化一格。再次点持握处或“松手”释放。
- 连接纹章：进入暂停编辑，点两个纹章建立关系，点“结束映射”后再移动。场景纹章与同名按钮功能一致。
- 点现有连线或连线按钮：进入编辑并断开，保持位置。重复选择相同一对也可断开。
- 方向键 / WASD：空手走路，持握时沿轨道推拉；E 抓 / 放，M 编辑，Z 撤回。
- 撤回恢复完整状态，包括失败与回位；重来恢复当前场景初值。
- “怎么玩”提供简短操作说明与清除通关标记。存储只保留已抵达学馆，刷新或重新进入场景恢复初值；独立存储键保留旧版本数据。

实验台没有通关判定，不阻挡进入其他学馆。提示需主动点击，最多三层。不预设答案或自动拼连线。

## 机制检查

`npm test`：40 项通过。覆盖不跳位置、保持位置差、统一长度、轴向变化、全组阻挡、无欠位移、环与自连不倍增、未映射子物件约束、父子合法映射、同时抵消、子轨道承载、回位与持握、编辑暂停、支撑中间态、人体不能制动、行走不能穿过薄墙、完整撤销与合法替代解。

`npm run verify:puzzles`：五题参考路线均松手后稳定且玩家实际到达出口，41 / 26 / 16 / 21 / 59 次操作。次数包含走路、抓放和编辑，仅为复现记录，不作为体验时长或难度证据。

`npm run build`：生成 `dist/index.html`，脚本、样式、图标与许可内联。产物不进入 Git。静态语法与资源检查通过；没有断网或 `file://` 实际浏览器验收。

## 浏览器验收

在本地 HTTP 预览完成：

- 从庭院进入两实验台，连接横竖滑块、从另一端驱动、走近车内推拉处，再推车。
- 五道谜题均通过 UI 操作真实走到出口；第二题保留把手额外连接也通关。
- 第三题先单推失败，再连接房间和天球。核对天球 SVG 世界位置在三次推进前后相同，房间与子轨道右移。
- 第四题先稳桥再换手推车；终局保留两个关系组并重复短把手往返。
- 房间运输中断开桥关系，退出编辑触发支撑失败；撤回恢复到持握车厢、映射编辑暂停的完整前态。
- 编辑期间方向键不能移动。手机宽度使用大按钮走近、抓取、连接与推拉。
- 390 像素入口和实验台、320 像素长标题场景无横向溢出。测试后恢复默认视口。
- 浏览器错误日志未发现脚本错误。清除本轮测试生成的通关标记，入口恢复供用户试玩。

这是开发者验收，不是独立新玩家试玩。

## 白盒边界

1. 物件用一个本地标量刻度，操作单位为整格，不模拟摩擦、质量、惯性或任意旋转。
2. 相对坐标从承载树递归计算；每次共同运动建立候选后统一校验。碰撞使用二维连续扫掠矩形，房间仅以甲板和柱体表现。
3. 固定导环用子物件的世界坐标约束代替完整三维细轴与孔壁；两个运输场景用桥完全展开时允许中途运输的支撑规则。此规则检查共同运动的中间路径。
4. 桥地板不携带玩家，撤走会失败；房间地板会携带玩家。装饰与透视深度不提供额外碰撞。
5. 回位在一个操作结束后结算到稳定，渲染显示这一操作前后的变化；不会逐帧展示每一格自动回位过程。
6. 最后两题的完整支撑接触、三维碰撞、手机小场景辨识和机制趣味仍需进一步制作与玩家测试。本次先交付可玩机制 Demo。
